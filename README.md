# ✨ Features

-   ✅ Secure Login
-   ✅ Multi User Support
-   ✅ Admin Dashboard
-   ✅ Folder Management
-   ✅ Drag & Drop Upload
-   ✅ ZIP / RAR / PDF / Excel / Word Support
-   ✅ Activity Logs
-   ✅ Device Tracking
-   ✅ Responsive Design

# 🛡 Security

-   🔐 Bcrypt Password Hashing
-   🔑 Session Authentication
-   🛡 Rate Limiter
-   📜 Activity Logs
-   🌍 Device Detection

          🌐 Vercel Hosting
